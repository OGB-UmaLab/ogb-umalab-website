X貼り付け技術検証・試作版

見出しを太字にして、Xへ貼り付けられるか試す

ChatGPT・メモ帳・Wordなどの文章を貼り付け、見出しを太字にした原稿をコピーします。X側で太字が保持されるかは未確認です。 このページは検証専用で、Xへの自動投稿は行いません。

「## 見出し」「### 小見出し」「**強調**」を変換します。Markdownの記号がない場合は、行頭の【 】で始まる行も見出しとして太字にします。

Wordなどの書式付き文章は、この編集欄へ直接貼り付けても構いません。必要に応じて文字を選択して太字ボタンを押してください。

③ Xで確認する

  1. 「書式付きでコピー」をクリックします。
  2. X Premiumの長文投稿画面を開き、本文欄に通常の貼り付け（Ctrl + V）をします。
  3. 「国内競馬NEWS」「【大井競馬】重賞結果」などが太字のまま表示されるか確認してください。

このページで太字に見えても、Xへの転送成功を意味しません。Xが貼り付け時に書式を破棄する場合、HTMLのコピー方法を変えるだけでは解決しない可能性があります。
