使い方・集計上の注意

返金予定額は「受付」「返品確認中」「返金待ち」「返金完了」の案件について集計します。「対応終了（返金なし）」は返金額の集計から除外します。返金完了は全額返金済みとして扱い、部分返金は一つの案件では管理できません。

この台帳は作業管理用です。販売サイト・決済サービスとの自動連携、実際の返金実行、売上・手数料・税額・在庫への自動反映は行いません。案件情報はこのブラウザ内で処理し、このツールからサーバーへ送信しません。ページを閉じる前にCSVまたは任意の端末内保存を行ってください。自動保存はありません。購入者の氏名・住所などの個人情報は入力しないでください。
