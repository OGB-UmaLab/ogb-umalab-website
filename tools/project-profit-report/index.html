案件別採算・作業時間集計

案件ごとの報酬、直接経費、実作業時間を記録し、直接経費控除後の利益と1時間あたりの金額を確認します。フリーランスや小規模な受託事業の価格・作業時間の見直しに利用できます。

1. 案件ごとの報酬・経費・作業時間を入力

CSVを用意しなくても試せます。

報酬・経費がない場合は0円、作業時間がない場合は0分を入力します。

作業時間を「時間・分」で入力する

時間と分を入力してください。

入力時の注意事項

同じ案件IDの明細は合算されます。案件名は同一にしてください。報酬と経費は同じ税込・税抜方式で入力し、作業時間は分単位の整数で記録します。作業だけの行は金額0、報酬だけの行は時間0とし、同じ報酬を重複計上しないでください。

見出し：案件ID,案件名,報酬額,直接経費,作業時間（分）

CSVで読み込み・編集する（任意）

2. 案件の採算を確認する

入力して集計してください。
案件ID案件名報酬直接経費差引利益作業時間（分）時間あたり利益
計算の考え方

差引利益＝報酬－直接経費。時間あたり利益＝差引利益×60÷作業分数（1円未満はゼロ方向に切り捨て）。作業時間が0の場合は算出不可です。これは直接経費だけを差し引いた採算指標で、固定費・税金・社会保険料を差し引いた所得や賃金ではありません。

請求額の回収確認には 請求・売掛金・入金管理、年間の所得集計には 年間売上・経費・所得集計 を利用できます。

入力データはブラウザ内で処理し、サーバーへ送信しません。自動保存は初期状態では無効です。端末内保存を使う場合は共有端末での取扱いに注意してください。元データと集計CSVを手元に保存してください。
