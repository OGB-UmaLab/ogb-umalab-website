取引先台帳・案件進捗管理

取引先ごとに仕事を登録し、納期・作業進捗・契約額の参考情報を確認します。案件の完了は請求済み・入金済みを意味しません。請求・入金は別の管理ツールで確認してください。

1. 取引先を登録

ID取引先名担当・連絡先メモ操作

2. 案件を登録・更新

3. 案件一覧・納期確認

ID取引先案件名進捗納期契約額等次の作業・メモ操作

4. 採算・請求書への引継ぎ

登録済みの案件を選択します。採算集計には案件ID・名称のみを引き継ぎ、報酬・経費・作業時間は実績を入力します。請求書には取引先・案件名と契約額の参考値を渡し、実際の請求額・税区分を確認します。

請求・売掛金・入金管理で入金状況を別途確認できます。

5. 入力を保存・復元

自動保存はしません。取引先の連絡先などが含まれるため、共有端末での保存は避け、バックアップは安全に保管してください。

対応範囲

取引先500件・案件1,000件まで。納期超過は未完了の案件で基準日より納期が前の場合に表示します。契約額は収入・請求額・売掛金残高とは異なり、確定申告へ自動転記しません。入力はブラウザ内で処理し、サーバーへ送信しません。
