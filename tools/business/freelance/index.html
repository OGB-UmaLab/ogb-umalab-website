個人事業主・フリーランスの業務ツール

請求・入金から日常の経費管理、資金計画、年間所得集計、確定申告の準備まで、仕事の流れに沿って利用できる共通ツールを紹介します。

各ツールは独立して動作し、入力は自動共有されません。対応するCSVを保存・読み込んで連携します。税務の各種計算は参考用で、正式な申告書の作成・提出や税務判断は行いません。

CSVでつなぐ業務

請求・入金管理 → 資金繰り計画。未入金予定を確認して入出金の見通しを立てます。

家事按分・減価償却費・経費集計 → 年間所得集計 → 所得税 → 住民税 → 納税資金。同じ経費の重複を除き、対象期間を確認してから反映します。

1. 受注・報酬・入金管理

  1. 案件別採算・作業時間集計

    報酬・直接経費・実作業時間を案件別に確認。

    案件別採算・作業時間集計を開く

  2. 請求・売掛金・入金管理

    請求金額と入金済額から未入金・期限超過を確認。

    請求・売掛金・入金管理を開く

  3. 報酬の源泉徴収税額計算

    対象となる報酬の差引額を確認。

    報酬の源泉徴収税額計算を開く

2. 経費・資金管理

  1. 経費科目別支出集計

    支出を科目別に整理。

    経費科目別支出集計を開く

  2. 家事按分・事業経費計算

    私用と事業用を兼ねる支出を整理。

    家事按分・事業経費計算を開く

  3. 減価償却費計算

    通常の定額法による償却額を確認。

    減価償却費計算を開く

  4. 月別資金繰り計画

    今後12か月の残高を試算。

    月別資金繰り計画を開く

3. 年間所得・確定申告の準備

  1. 年間売上・経費・所得集計

    売上と必要経費を年間集計。

    年間売上・経費・所得集計を開く

  2. 所得税・復興特別所得税

    青色申告特別控除の比較と概算税額。

    所得税・復興特別所得税を開く

  3. 住民税・森林環境税

    翌年度の住民税等を試算。

    住民税・森林環境税を開く

  4. 消費税概算・課税方式比較

    適用条件を確認した課税方式を比較。

    消費税概算・課税方式比較を開く

  5. 納税資金管理

    税額から準備額を試算。

    納税資金管理を開く

4. 個人・副業の申告準備

  1. 副業・雑所得・一時所得集計

    給与所得と副業等の所得を整理。

    副業・雑所得・一時所得集計を開く

  2. 確定申告の必要性確認

    給与所得者の一般的な申告条件を確認。

    確定申告の必要性確認を開く
