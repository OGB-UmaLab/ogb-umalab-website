ネット物販事業の業務ツール

出品準備から受注・発送・入金・在庫・利益管理まで、ネット物販の仕事の流れに沿って使える無料ツールをまとめました。

今日やりたいことを選ぶ

商品を登録する商品名・原価・販売価格を管理いくらで売るか決める目標利益から必要価格を計算出品写真を準備する画像をまとめて変換今の在庫を確認する入荷・出荷の数量を集計注文した商品が届いたか確認未入荷数量と金額を確認注文と入金を照合する決済の不一致を確認

対応するツールでは、計算結果の「次のツールへ直接引き継ぐ」ボタンからCSV保存・再読み込みを省略できます。引継ぎ先で読み込む操作が必要です。下の業務一覧のリンクは画面移動のみで、入力は自動共有されません。必要な入力・保存・確認操作は各ツールで行ってください。

業務セットを登録して繰り返し使う（任意）

直接引継ぎで進める仕事

商品登録から仕入・利益集計

商品名・SKU・出品準備 → 商品台帳・出品状況管理 → 入出庫・現在庫集計 → 在庫・発注点チェック → 仕入発注・入荷照合 → 商品別粗利益・利益率集計

SKU・在庫数・発注目安・入荷済み原価などを渡し、空欄に実績を入力します。仕入単価は原価候補です。

商品原価・送料から目標販売価格

商品台帳 または 配送コスト集計 → 販売先別利益比較 → 販売価格の逆算

対象商品・配送方法・販売先を選択します。平均配送費は実績から算出した出品者全額負担時の目安で、逆算では費用の二重計上がないか確認してください。

価格を決定して出品準備へ

販売価格の逆算 → 商品台帳 → 登録済み商品の出品準備

単品または一括試算の価格を選択して既存SKUの販売価格欄だけを更新し、商品名・SKU・価格を出品準備でコピーできます。出品サイトへの自動登録は行いません。

受注から決済・発送・返品

注文明細集計 → 注文・決済照合 → 発送・梱包チェック → 返品・返金管理

決済照合後は一致した注文だけを発送チェックに渡せます。決済確認なしの発送準備とは区別します。

販売・発送実績から利益と在庫を確認

注文明細CSV → 商品別利益集計 または 入出庫・現在庫集計

実際の販売明細からSKU・数量・費用などの列を指定します。発送済み出庫は開始在庫を登録したSKUに限り、同じ識別情報の再取込を防ぎます。利益集計は対象期間の全明細を入れ替えます。

販売先別の利益と返金を確認

注文明細CSV → 販売チャネル別利益集計 ← 返品・返金管理

実績列を指定して対象期間の明細を入れ替えます。返金完了案件は販売先と対象期間を確認して参考比較に反映します。元の収支・年間所得・在庫は自動変更しません。

年間収支から納税準備

商品別粗利益・利益率集計 → 年間売上・経費・所得集計 → 所得税・復興特別所得税 → 納税資金管理

対象期間と重複、税務上の金額を確認しながら反映します。

1. 仕入れ・入荷・在庫

  1. 入出庫・現在庫集計

    SKU別の在庫増減から現在庫を確認し、発注点計算用ひな形を保存。

    入出庫・現在庫集計を開く

  2. 仕入発注・入荷照合

    発注数量と入荷数量を照合し、未入荷金額を確認できます。

    仕入発注・入荷照合を開く

  3. 仕入請求・支払照合

    仕入先の請求金額と支払済金額を照合し、未払・過払を確認できます。

    仕入請求・支払照合を開く

  4. 在庫・発注管理

    発注点・補充数量を確認

    在庫・発注管理を開く

  5. 棚卸差異・在庫評価

    帳簿在庫と実棚在庫を照合し、過不足数量と評価額を確認できます。

    棚卸差異・在庫評価を開く

  6. 滞留在庫・在庫年齢分析

    最終入荷日からの経過日数で在庫を区分し、原価評価額を確認できます。

    滞留在庫・在庫年齢分析を開く

2. 商品登録・撮影・価格設定

  1. 商品台帳・出品状況管理

    SKU・商品名・原価・販売価格・出品状況を継続管理できます。

    商品台帳を開く

  2. 商品登録・出品準備

    商品名・SKUを一括準備

    商品登録・出品準備を開く

  3. 出品写真の準備

    画像のサイズ変更・圧縮

    出品写真の準備を開く

  4. 販売価格の検討

    販売先ごとの利益を比較

    販売価格の検討を開く

  5. 販売価格・利益試算

    原価・固定費・手数料から目標利益に必要な販売価格を逆算します。最大500商品の一括計算にも対応します。

    販売価格・利益試算を開く

3. 受注・発送・入金・返品

  1. 注文データの集計

    注文行をまとめて集計

    注文データの集計を開く

  2. 梱包・発送準備

    注文ごとの発送前確認

    梱包・発送準備を開く

  3. 配送方法別送料・配送コスト集計

    配送方法ごとに顧客請求送料と実費を比較できます。

    配送方法別送料・配送コスト集計を開く

  4. 入金・決済照合

    注文と決済の差異を確認

    入金・決済照合を開く

  5. 返品・返金への対応

    返品案件と返金状況、未完了額を確認できます。

    返品・返金への対応を開く

4. 利益・経費の確認

  1. 商品別粗利益・利益率集計

    SKU別に売上・原価・手数料・送料をまとめ、商品ごとの利益率を確認できます。

    商品別粗利益・利益率集計を開く

  2. 販売チャネル別利益集計

    販売先別の売上・原価・手数料・送料と利益率を比較できます。

    販売チャネル別利益集計を開く

  3. 収益の確認

    利益・損益分岐点を計算

    収益の確認を開く

  4. 経費科目別支出集計

    広告費・消耗品費などの支出を科目別に集計できます。

    経費科目別支出集計を開く

5. 売掛金・資金繰り

  1. 請求・売掛金・入金管理

    請求額、未入金額、期限超過を確認。

    請求・売掛金・入金管理を開く

  2. 月別資金繰り計画

    入出金予定から今後12か月の残高を試算。

    月別資金繰り計画を開く

年間集計・確定申告の準備

年間の売上・原価・経費を確認し、対応するCSVを取り込んで所得を集計します。 年間売上・経費・所得集計 ／ 税金・確定申告カテゴリー

各ツールは用途を限定した補助機能です。会計・税務・配送などの業務全体を自動処理するものではありません。
