ネット物販事業の業務ツール

出品準備から受注・発送・入金・在庫・利益管理まで、ネット物販の仕事の流れに沿って使える無料ツールをまとめました。

各ツールは独立して動作します。ツール間で入力内容は自動連携されません。対応しているCSV形式・機能は各ツールの説明を確認してください。

CSVでつなぐ日常業務

SKU発番 → 在庫・発注点チェック → 仕入発注・入荷照合 → 商品別利益集計

各工程のCSVひな形を保存し、空欄に実績を入力して次のツールへ読み込みます。仕入単価は原価候補です。

注文明細集計 → 発送チェック または 決済照合。注文集計CSVを利用できます。

1. 仕入れ・入荷・在庫

  1. 仕入発注・入荷照合

    発注数量と入荷数量を照合し、未入荷金額を確認できます。

    仕入発注・入荷照合を開く

  2. 仕入請求・支払照合

    仕入先の請求金額と支払済金額を照合し、未払・過払を確認できます。

    仕入請求・支払照合を開く

  3. 在庫・発注管理

    発注点・補充数量を確認

    在庫・発注管理を開く

  4. 棚卸差異・在庫評価

    帳簿在庫と実棚在庫を照合し、過不足数量と評価額を確認できます。

    棚卸差異・在庫評価を開く

  5. 滞留在庫・在庫年齢分析

    最終入荷日からの経過日数で在庫を区分し、原価評価額を確認できます。

    滞留在庫・在庫年齢分析を開く

2. 商品登録・撮影・価格設定

  1. 商品台帳・出品状況管理

    SKU・商品名・原価・販売価格・出品状況を継続管理できます。

    商品台帳を開く

  2. 商品登録・出品準備

    商品名・SKUを一括準備

    商品登録・出品準備を開く

  3. 出品写真の準備

    画像のサイズ変更・圧縮

    出品写真の準備を開く

  4. 販売価格の検討

    販売先ごとの利益を比較

    販売価格の検討を開く

  5. 販売価格・利益試算

    原価・固定費・手数料から目標利益に必要な販売価格を逆算します。最大500商品の一括計算にも対応します。

    販売価格・利益試算を開く

3. 受注・発送・入金・返品

  1. 注文データの集計

    注文行をまとめて集計

    注文データの集計を開く

  2. 梱包・発送準備

    注文ごとの発送前確認

    梱包・発送準備を開く

  3. 配送方法別送料・配送コスト集計

    配送方法ごとに顧客請求送料と実費を比較できます。

    配送方法別送料・配送コスト集計を開く

  4. 入金・決済照合

    注文と決済の差異を確認

    入金・決済照合を開く

  5. 返品・返金への対応

    返品案件と返金状況、未完了額を確認できます。

    返品・返金への対応を開く

4. 利益・経費の確認

  1. 商品別粗利益・利益率集計

    SKU別に売上・原価・手数料・送料をまとめ、商品ごとの利益率を確認できます。

    商品別粗利益・利益率集計を開く

  2. 販売チャネル別利益集計

    販売先別の売上・原価・手数料・送料と利益率を比較できます。

    販売チャネル別利益集計を開く

  3. 収益の確認

    利益・損益分岐点を計算

    収益の確認を開く

  4. 経費科目別支出集計

    広告費・消耗品費などの支出を科目別に集計できます。

    経費科目別支出集計を開く

年間集計・確定申告の準備

年間の売上・原価・経費を確認し、対応するCSVを取り込んで所得を集計します。 年間売上・経費・所得集計 ／ 税金・確定申告カテゴリー

各ツールは用途を限定した補助機能です。会計・税務・配送などの業務全体を自動処理するものではありません。
