飲食店の営業日報・売上分析

営業終了後に、営業区分ごとの売上・客数をまとめて記録します。決済別売上はレジ締めや月次売上集計にも使えるため、日次売上台帳への二重入力は不要です。1店舗・同じ税込／税抜基準で利用してください。

1. 営業日報を登録する

営業した区分だけチェックし、売上を決済方法ごとに入力します。客数は来店人数など同じ基準で、営業区分間の重複を避けてください。売上がある営業は客数1以上が必要です。目標0は未設定。返品等は調整済みの非負の売上を入力してください。

同じ営業日を登録すると、確認後にその日の日報全体を置き換えます。夜間営業の日付は店舗の営業日基準で統一してください。

2. 営業日別・月別の実績

日報を登録してください。

営業日売上客数客単価現金売上目標達成率操作

営業区分別（ランチ・ディナー・その他）

区分営業回数売上客数客単価売上構成比

曜日別の傾向

曜日営業日数売上1日平均売上客数客単価

月別の売上・客数

対象月営業日数売上客数客単価目標達成率

客単価は売上合計÷客数合計（円未満切捨て）。目標達成率は目標を設定した日だけを集計します。平均売上は登録された営業日数で割ります。休業日は登録不要です。

3. レジ締め・月次売上へ

表示対象月の日報を決済別売上CSVに変換して直接引き継ぎます。レジ締めには上で選んだ1営業日だけを渡します。既存の日次売上台帳に同じ売上を二重登録しないでください。

4. 日報を保存・復元

日報CSVを取り込む・全件削除

このツールの全日報CSVを読み込めます。同じ日付はその日の日報全体を置換し、他の日付は維持します。

自動保存は行いません。移動前に端末内保存か日報CSV保存をしてください。POS・会計帳簿の代替ではありません。共有端末では個人情報を入力しないでください。
