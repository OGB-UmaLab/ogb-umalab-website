商品明細CSVを注文番号別に集計

ネットショップのCSVが「商品1点につき1行」になっている場合に、注文番号ごとの合計金額を作ります。集計したCSVは受注・決済CSV照合ツールでそのまま読み込める列構成です。

架空のCSVをダウンロードして、集計から照合まで無料で体験する →　／　練習用の注文明細CSVを保存

各行にある金額が「その明細行の合計」である場合に利用してください。注文総額がすべての明細行に繰り返されているCSVを合算すると、金額が過大になります。送料・値引き・税額の扱いも確認してください。

1. 明細CSVを選ぶ

2. 列を指定して集計

3. 集計結果

CSVを読み込んでください。

検索した場合は該当する注文の先頭200件を表示します。「注文別集計CSV」は検索に関係なく全注文を保存します。「検索結果だけCSV」は検索に一致する全注文を保存します。

注文番号注文別合計（選択列の合計）明細行数

使い方と注意点

  1. 商品明細CSVを出力し、各行の金額が「行ごとの合計」であることを確認します。
  2. 注文番号列と金額列を指定して集計します。
  3. 注文別の合計を確認し、CSVを保存します。
  4. 受注・決済CSV照合で、決済側の同じ定義の金額と比較します。

金額とデータの扱い

金額は円単位の整数を想定します。金額に小数、空欄、不正値が含まれる場合は集計を停止します。注文番号が空欄の行も停止対象です。先頭ゼロと大文字・小文字は区別します。重複行の削除は行いません。集計対象に同じ明細が重複していないか、元データを確認してください。

CSVの列名は重複できません。金額途中の空白は不正値として停止します。結果CSVではExcelの数式と解釈され得る注文番号を無害化します。Excelで開く場合は先頭ゼロを保持するため注文番号列を文字列として取り込んでください。

読み込んだCSVはブラウザ内で処理し、集計のために当サイトのサーバーへ送信しません。

次の作業：決済データと照合する

集計結果をCSV保存したら、受注・決済CSV照合ツールの受注側に読み込み、決済側CSVと注文番号・金額を比較します。決済手数料や返金などの扱いが異なる場合は、同じ金額定義にそろえてください。
