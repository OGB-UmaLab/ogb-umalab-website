無料ツールで困ったときの確認事項

CSV・PDF・画像を扱うツールで、ファイルが読み込めない、結果が合わない、保存できないといったときの確認手順をまとめました。エラーが出た場合は元ファイルを残し、まず小さなサンプルで同じ操作を試してください。

症状から探す
  • CSVの文字化け・列ずれ
  • 注文集計・決済照合の金額差
  • PDFが読み込めない・保存できない
  • 画像が読み込めない・容量が減らない
  • リストの重複が残る
  • 保存やダウンロードがうまくいかない

CSVの文字化け・列ずれ

日本語が文字化けする

  1. CSVを出力したサービスやソフトで、文字コードを確認する。
  2. 文字コード選択があるツールではUTF-8とShift_JISのうち、ファイルに合う方を選ぶ。
  3. 読み込み直して、列見出しと数件の値が正しいか確認する。

文字コードを選択できるツールと、選択欄のないツールがあります。元CSVの保存形式を変える際は別名で保存し、元ファイルを残してください。

列がずれる・読み込みエラーになる

見出し行、列数、引用符の閉じ忘れ、セル内改行を確認します。CSVの値にカンマを含む場合、適切なダブルクォート囲みが必要です。CSV結合とCSV分析は目的が異なるため、複数ファイルの統合が必要なら先に結合してください。

Excelで注文番号の先頭ゼロが消える

00123 のようなIDは数値ではなく文字列です。ExcelでCSVを開く際はID列を文字列として取り込んでください。IDの先頭ゼロが消えると照合で一致しなくなることがあります。

注文集計・決済照合の金額が合わない

  1. 注文単位集計の入力CSVが、商品1行ごとの金額なのか、注文総額を繰り返し記載しているのか確認する。後者を足すと過大計上になります。
  2. 受注側と決済側の金額の定義をそろえる。税込・税抜、送料、値引き、手数料差引前後を混在させない。
  3. 注文番号・取引IDの前後の空白、先頭ゼロ、大文字・小文字を確認する。
  4. 決済照合の「受注のみ」「決済のみ」「金額不一致」「ID重複」を確認し、必要なら結果CSVを保存する。

同じ注文番号が複数行ある場合、照合ツールは自動で合算せず重複IDとして扱います。注文単位に集計してから照合してください。銀行口座への実際の入金確認や返金・分割入金の自動調整は行いません。

架空のCSVを使った集計・照合の実践ガイド

PDFが読み込めない・保存できない

  1. PDF分割ツールはパスワード保護PDFに対応していません。保護の有無を確認する。
  2. 外部配信のPDF処理ライブラリを読み込むため、初回はネット接続が必要です。読み込みが進まない場合は通信状態を確認する。
  3. 指定したページ範囲が元PDFのページ数内か確認する。
  4. 出力ファイル数とファイル名の行数を一致させ、名前の重複や使えない記号を避ける。
  5. 「分割内容を確認」でプレビューしてからZIPを保存する。

電子署名、フォーム、注釈などの特殊な機能は元の状態が維持される保証がありません。保存したPDFを開き直して確認してください。

画像が読み込めない・容量が減らない

  1. 画像一括変換はJPEG・PNG・WebP・BMP・GIFに対応し、HEIC・SVGは対象外です。GIFは静止画として変換されます。
  2. 最大50枚、1枚30MBまでです。選択枚数と各ファイルの容量を確認する。
  3. JPEG・WebPでは画質と目標容量を調整できます。PNGは画質設定や目標容量の指定が適用されず、容量が増えることもあります。
  4. 縮小後の写真を拡大表示し、文字や商品の細部が読めるか確認する。

目標容量は必ず達成されるわけではありません。画像の明るさ自動補正や正方形への自動切り抜きは現在の機能に含まれません。

商品写真の一括変換ガイド

リストの重複が残る

リスト整理は行全体の一致を基準に比較します。前後の空白除去や英字の大文字・小文字の同一視を選べますが、全角半角・語順・社名表記の違いを自動で統一する機能はありません。表記ゆれをそろえてから再実行してください。

リスト整理の実践ガイド

結果を保存・ダウンロードできない

  1. 入力後に「実行」「変換」「分割内容を確認」など必要な操作を完了しているか確認する。
  2. ブラウザのダウンロード履歴・保存先を確認する。
  3. 画像の個別一括保存では、ブラウザによって複数ダウンロードの許可が必要な場合があります。ZIP保存も試してください。
  4. 大容量のファイルを多数処理している場合は、少数に分けて再実行する。

入力データを失わないよう、元ファイルは必ず別途保管してください。
