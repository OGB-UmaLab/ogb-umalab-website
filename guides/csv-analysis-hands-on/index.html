無料で試せる実践ガイド

10日分の売上CSVを分析してみよう

架空の店舗の売上・客数を使い、CSV自動分析ツールで合計・平均・最大値・日別推移を確認します。自分のデータは必要ありません。

1. 練習用CSVを保存する

10日分の売上CSVをダウンロード

日付、売上、客数の3列で、2026年11月1日から10日までの10行です。データは架空のものです。

2. CSV分析ツールで読み込む

  1. CSV自動分析ツールを開きます。
  2. 「CSVファイルを選択」で保存したファイルを指定します。文字コードはUTF-8、先頭行を項目名として使う設定にします。
  3. 読み込み後に、10行・3列と表示されることを確認します。
  4. 数値列「売上」の統計情報を下表と比較します。
売上の確認項目期待される値
データ行数10行
売上合計518,000円
売上平均51,800円
最小値25,000円
最大値100,000円

売上合計は10日分の売上をすべて足した値、平均は518,000÷10＝51,800円です。

3. 日付ごとの推移を確認する

  1. 「調べたいこと」で日付・月別の推移を選びます。
  2. 横軸を日付、縦軸を売上、集計方法を合計にします。
  3. 11月6日の売上100,000円が最大、11月3日の25,000円が最小になっているか確認します。
  4. グラフはPNG、集計表や統計レポートはCSVとして保存できます。

11月6日の売上が高い理由は、この架空データだけでは分かりません。実データであれば販促・営業日・客数などを照合して判断します。

4. 結合したCSVを分析する

複数店舗のデータが別々のCSVになっている場合は、先に3店舗のCSV結合体験を試すと、複数ファイルを1つにしてから分析する流れを確認できます。

統計量の意味を詳しく知りたい場合は、平均・中央値・外れ値・相関の基礎解説をご覧ください。
