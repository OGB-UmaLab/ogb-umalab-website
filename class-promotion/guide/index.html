クラス昇級可能馬データの見方

公開されている格付ポイントと各レースの番組ポイントをもとに、今回のレース結果によって次級の格付基準を突破する可能性がある馬をまとめたデータです。対象馬のいるレースのみ掲載しています。

1. このデータは何を示しているのか

各馬が現在持っている格付ポイントと、今回のレースで獲得できるポイントを確認し、今回のレース結果によって次級の格付基準へ到達する可能性がある馬を掲載しています。

2. 「次級基準突破可能馬」とは

「現在の格付ポイント＋今回の獲得ポイント」が、次級の格付基準以上となる可能性がある馬です。
各レースの対象馬について、何着以内に入れば次級の基準を突破するかを表示しています。

3. 着順別獲得ポイントの見方

各レースには、着順に応じて獲得できる番組ポイントがあります。

表示例

着順別獲得P：1着100P｜2着24P｜3着12P｜4着8P｜5着6P

この場合、1着は100ポイント、2着は24ポイント、3着は12ポイント、4着は8ポイント、5着は6ポイントを獲得することを示しています。

4. 基準突破表記の見方

「1着でC2基準突破」は、今回のレースで1着になると、現在の格付ポイントと獲得ポイントの合計がC2の格付基準へ到達することを示しています。

「3着以内で次級基準突破」は、1着、2着または3着になると、次級の格付基準へ到達することを示しています。

「5着以内」のように表示されている場合も同様に、表示された着順以内で基準へ到達する可能性があることを示します。

5. 実際の記事表示例

■6R　C2一 3歳以上

着順別獲得P：1着100P｜2着24P｜3着12P｜4着8P｜5着6P

次級基準突破可能馬

② ラスアルハイマ
5着以内でC1基準突破
騎手：田野豊三｜調教師：吉見真幸
馬主：椎名真生

この例では、ラスアルハイマが今回のレースで5着以内に入ると、現在の格付ポイントと今回の獲得ポイントの合計がC1の格付基準へ到達することを示しています。

6. このデータを確認する際の注意点

本データは、今回のレース結果によって次級の格付基準へ到達する可能性を示したものです。

実際に新しいクラスへ編成される時期を示すものではありません。

対象馬のいるレースのみ掲載しています。掲載されていないレースは、今回の対象馬がいないレースです。

競馬場ごとに格付基準、ポイント制度、クラス名称などが異なる場合があります。各記事では、対象となる競馬場の公開情報をもとにデータを掲載します。
