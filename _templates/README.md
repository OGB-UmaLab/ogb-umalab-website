# 園田競馬の記事用OGP

対象は `class-promotion/YYYY-MM-DD-sonoda/index.html` の「次級基準突破可能馬データ」のみです。OGB DATA、他場の記事、ニュース、一覧ページには適用しません。

このリポジトリには既存の記事生成テンプレート・生成スクリプトがないため、記事作成時に使う head 部品をここに用意しています。自動挿入されるものではありません。リポジトリ外の作成テンプレートがある場合は、同じ部品をその head に組み込んでください。

## 記事作成・公開時

1. 正しい当日の原稿から、従来どおり記事HTMLを作成します。
2. `sonoda-class-promotion-ogp.html` のメタタグを、その記事の `</head>` の直前に挿入します。既存の同名タグは重複させず置換します。JavaScriptで追加しないでください。
3. `{{TITLE}}` を `9月25日 園田競馬｜次級基準突破可能馬データ` のような当日のタイトルに置換します。
4. `{{DESCRIPTION}}` を記事の説明文に置換します。標準文は「今回のレースで何着以内に入れば次級の格付基準を突破するかを掲載しています。」です。
5. `{{ARTICLE_URL}}` を実際の公開絶対URLに置換します。通常は `https://ogb-umalab.com/class-promotion/YYYY-MM-DD-sonoda/` です。属性値内の `&`、`"`、`<` はHTMLエスケープしてください。
6. 本文・レイアウトは従来のまま公開し、記事・画像のHTTP 200と、配信HTMLの head 内の設定を確認します。Xの実表示はXで別途確認してください。

画像は `https://ogb-umalab.com/assets/ogp/sonoda-ogp.png` を今後も共通利用します。画像の再生成・加工・日付の追加は不要です。

2026年9月25日の実装例は `class-promotion/2026-09-25-sonoda/index.html` の head で確認できます。以降の記事は共通部品のタイトル・説明文・記事URLを更新し、同じ固定画像を参照してください。
