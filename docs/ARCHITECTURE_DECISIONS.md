## 作業管理の運用ルール

1. まずマスタープランと台帳を確認する。
2. 進行中フェーズの完了条件に直結する作業を選ぶ。
3. 新たな課題は本台帳またはバックログに記録する。優先度A以外は作業の主目的を変えない。
4. 作業終了時に「実装済み」「構文確認済み」「ブラウザ動作確認済み」を区別して報告する。
5. 重要なサイト構成の変更は、決定根拠を台帳に残してから実施する。
